# Team Performance Analysis

A data-driven project focused on **analyzing the performance of a Customer Service department** using service ticket metrics to uncover operational insights, optimize workflows, and enhance customer satisfaction.

## 📋 Project Overview
This repository contains a analysis of customer service ticket data. The goal of this project is to evaluate support team efficiency and performance,
understand common customer pain points, and identify actionable strategies to improve response times and resolution quality.

## 📊 Key Focus Areas
* **Ticket Metrics:** Analysis of ticket volumes, resolution rates, and backlog trends.
* **Response & Resolution Times:** Benchmarking First Response Time (FRT) and Time to Resolution (TTR).
* **Agent Performance:** Evaluating individual and team-level metrics to highlight top performers and training opportunities.
* **Customer Satisfaction:** Correlating ticket handling metrics with CSAT scores (if available in dataset).

* **Python** (100% Jupyter Notebook)
* **Pandas & NumPy** for data cleaning and manipulation
* **Matplotlib & Seaborn** for data visualization

## 🚀 Getting Started

### Prerequisites
Make sure you have Python installed, along with the required libraries:
```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Running the Analysis
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project directory:
   ```bash
   cd Team-performance-Analysis
   ```
3. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
4. Open the file inside the `Team Performance Analysis` folder to view the full pipeline.
* Bottleneck detection in ticket routing or specific issue categories.
* Performance scorecards to streamline internal customer service KPIs.
